# feat-025 — live browser pass (T-03)

**When:** 2026-09-01 · `localhost:3000` · a record whose Free-text field holds a four-line
JavaScript block, seeded in the database so both views render the same document.

## The two mechanisms agree

The read view wraps each line in `.nb-codeLine` and numbers it with a CSS counter; the editor
cannot touch its document and numbers with widget decorations. Two implementations, one geometry —
which is exactly why this needed measuring rather than asserting.

| | read view | editor |
|---|---|---|
| lines rendered | **4** | **4** — numbers `1 2 3 4` |
| gutter width | 26px | 26px |
| gutter margin-right | 10px | 10px |
| gutter border-right | 1px | 1px |
| hanging indent | `padding-left: 42px` / `text-indent: -42px` | identical |

In the editor the gutter's left edge sits at x=518 and the first code character at x=554 — 36px
apart, which is the 26px gutter plus its 10px margin. The numbers line up with the text they
belong to.

## The property that mattered most: copying

A widget decoration is not part of the document, and this is the check that proves it rather than
asserting it. The whole code block was selected and a real `copy` event dispatched at the editor:

```
browser selection      "const a = 1;\nconst b = 2;\nconst c = 3;\nconsole.log(a + b + c);"
ProseMirror clipboard  "const a = 1;\nconst b = 2;\nconst c = 3;\nconsole.log(a + b + c);"
text/html flavour      <pre data-language="javascript"><code>const a = 1;…
```

**No digit in any flavour.** Pasting code with line numbers woven into it is the single most
annoying thing a code block can do, and it does not happen here.

`user-select: none` is set as well — belt and braces for a selection dragged across the block.

## Note on the test that nearly lied

The first version of the C-08 assertion only checked that `getHTML()` contained no digits. A
mutation that wove the numbers into the document did **not** break it, because the test never
proved the numbers existed — "no numbers in the output" was true for the wrong reason. It now
asserts both halves against a mounted view: the gutter renders, and the serialization is clean.
Both mutations kill it.
