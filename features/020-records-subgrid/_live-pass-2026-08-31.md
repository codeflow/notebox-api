## 3. Defect found and fixed — the failure notice's border

The failure notice rendered with a **red border instead of the theme's soft `#d98c8c`**:

```
before  border: 1px solid rgb(176, 0, 0)     ← currentColor, i.e. the text red
after   border: 1px solid rgb(217, 140, 140) ← #d98c8c, the theme's error edge
```

**Cause.** T-09 wrote `border: 1px solid` — the *shorthand*, which resets `border-color` to
`currentColor`. That rule sits after `.nb-msg-error` in the file, so it overrode the severity
colour it was meant to complete. **Fix:** set `border-width` and `border-style` separately and let
`.nb-msg-error`'s `border-color` stand.

No test could have caught this. `classCoverage` only proves a rule *mentions* the class; jsdom
computes no styles at all. It took reading `getComputedStyle` in a browser.

Verified after the fix, with the component's own markup rendered inside a real band:
red text `rgb(176,0,0)`, the `#fdecec → #f8d4d4` gradient, a **1px solid `#d98c8c`** border, 3px
radius, `inline-block` sized to its content (189×23) rather than stretched across 1115px.

## 5. What this pass could NOT verify — keyboard activation

Pressing Enter on the focused twisty did not open the band **in the automation harness**, and this
is a harness limitation, not a defect. Proof: a freshly created plain `<button>` with an `onclick`,
focused and sent the same Enter, also received `keydown` (`Enter@BUTTON`) and produced **no click**.
Synthetic key events in this pane do not trigger native button activation for *any* button.

Mouse activation was verified live: a real click at the twisty's coordinates toggles the band and
leaves its neighbour's band untouched.

**Keyboard activation therefore rests on T-07's jsdom tests** (`userEvent` does produce activation),
plus `aria-expanded` which was read directly off the live DOM as `false`/`true` per row. Stated
here rather than glossed, because "the live pass covered the keyboard" would be false.

## 6. Observations, not defects

- The twisty's click target is **9×9px** inside the 28px lane — small, but identical to the
  navigator's twisty, so it is app-consistent. Worth a product decision some day; not this feature's
  to change unilaterally.
- One early click missed before React had hydrated; after hydration every click landed. Not a
  defect — a note for whoever automates this screen next.

## 7. Corrections made during the pass

An early measurement reported **11** rows in the band. Wrong: `grid.querySelectorAll('tbody tr')`
matches the inner table's `thead > tr` too, because that row still descends from the *outer*
table's `tbody`. The inner `tbody` has exactly **10** children. Recorded because the same trap
would fool anyone re-running these measurements.
