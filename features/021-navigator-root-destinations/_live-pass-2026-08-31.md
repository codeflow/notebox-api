## 2. Defect found and fixed — the root was current only for a screen reader

On `/annotation-types`, the Annotations root carried `aria-current="page"` but its row was
`af-treeRow` with background `rgba(0,0,0,0)` — **no `nb-treeRow-selected`**. Leaves and the
Administration destinations both get that class when current. So the root announced itself to
assistive technology and showed nothing to anyone looking at the screen.

The jsdom test passed: it asserted `aria-current`, which was correct as far as it went. The
missing half is invisible without a stylesheet — the same class of gap feat-020's live pass found.

**Fix:** the root rows now carry `nb-treeRow-selected` on the same condition, matching the
Administration precedent the plan set out to reuse. Test extended to assert both halves, in both
directions.

**After the fix, measured live:**

| Route | Root row class | Background | `aria-current` |
|---|---|---|---|
| `/annotation-types` | `af-treeRow nb-treeRow-selected` | `rgb(219,230,242)` | `page` |
| `/annotation-types/{id}/records` | `af-treeRow` | `rgba(0,0,0,0)` | absent |

Row height stayed **18** with the highlight applied — the selection does not move the layout.
